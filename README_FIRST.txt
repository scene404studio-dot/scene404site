SCENE404 STUDIO — WEBSITE REFRESH
================================

This package contains updated versions of the existing website files plus a new master brief.

IMPORTANT:
- This is a replacement package, not a magic add-on. HTML files do not automatically inherit instructions from the brief.
- Upload these files to the ROOT of your existing GitHub repository.
- When GitHub asks whether to replace an existing file with the same name, choose replace/update.
- Do not delete your existing image files. The pages use the image filenames already shown in your repository.
- Keep filename capitalization exactly as it is in the repo (for example, brb-logo.PNG and moments.PNG).
- The package does not include copies of your existing images; it references them in the repository root.
- Back up the current files first by downloading them or using GitHub's file history.

Included:
- index.html
- brb.html
- world.html
- about.html
- style.css
- script.js
- SCENE404_MASTER_BRIEF.md

Image path notes:
- Studio hero: world.png (existing)
- BRB hero: hero.png (existing)
- The World: existing brb-*.jpeg character artwork
- About hero: founders-note.PNG (existing blueprint/founder visual if that file contains the intended sketch)
- About Rare Edition: brb-one-in-a-million.jpeg (existing)

The BRB page includes a working image carousel built with HTML/CSS/JS. It uses the existing character image files. If a particular character image filename differs in your repository, update the matching filename in brb.html.

After uploading:
1. Open the Vercel deployment.
2. Check all four pages on desktop and phone.
3. Test carousel arrows, dots, and keyboard arrow keys.
4. Confirm the blueprint image file visually contains the blueprint artwork. If not, change the source to the correct existing filename.
5. Confirm One in a Million appears only on About.
