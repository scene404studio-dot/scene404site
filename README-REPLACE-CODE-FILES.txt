SCENE404 STUDIO — согласованный комплект кода

В комплекте только файлы кода: index.html, brb.html, world.html, about.html, style.css, script.js.
Изображения намеренно не включены и не переименованы: оставьте ваши существующие image-файлы в корне репозитория.

Как установить:
1. Сделайте backup текущих шести файлов.
2. Загрузите эти шесть файлов в ту же папку GitHub-репозитория, где лежат текущие index.html и изображения.
3. Подтвердите замену файлов. Не удаляйте изображения и остальные страницы (privacy.html, terms.html, contact.html, FAQ.html).
4. После публикации откройте сайт в приватной вкладке/сделайте hard refresh.

Проверено в комплекте: единые style.css и script.js подключены на всех четырёх страницах; HTML-теги закрыты; ссылки на моменты используют moments.PNG (точный регистр); на About золотой BRB встречается один раз; карусель персонажей работает на странице BRB, сетка персонажей — на The World.

Важно: форма подписки использует существующий Formspree endpoint xjgdddne из исходных страниц. Проверить фактическую отправку формы и внешний вид на опубликованном Vercel без доступа к вашему аккаунту здесь невозможно.
