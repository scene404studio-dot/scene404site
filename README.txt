SCENE404 studio — homepage image update

Contents:
- index.html: updated homepage using the existing site's style.css and existing page links.
- assets/: optimized copies of the uploaded BRB artwork.

How to use:
1. Back up the current index.html.
2. Copy the new index.html into the same root folder as the existing style.css and the other pages.
3. Copy the included assets folder into that same root folder.
4. Preview locally/mobile before deploying.

This package does not include or replace style.css, the other site pages, or Vercel deployment settings. It is not published live.
The first uploaded image was an Instagram editor screenshot, so it was intentionally not used as a website asset.
